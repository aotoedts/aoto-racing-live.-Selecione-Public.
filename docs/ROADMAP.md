# Estado do desenvolvimento

## Implementado no repositório
- Dois modos 3D: Racing e Funk Drift
- Corrida automática, voltas, vencedor e contagem regressiva
- HUD com botões simuladores de eventos
- Fumaça geométrica leve
- Música original sintetizada em tempo real, desativada por padrão
- Configurações locais e renderer Compatibility

- Carros esportivos detalhados com modelos próprios
- UI adaptativa para todas as resoluções
- Efeitos sonoros distintos de motor e colisão
- Música funk licenciada (não incluída)
- API oficial TikTok Live, backend, autenticação e eventos reais
- APK de distribuição, desempenho validado e publicação

O projeto é um protótipo avançado, não um produto final validado.
