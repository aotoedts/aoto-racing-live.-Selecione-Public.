# AOTO Racing Live

Prototipo inicial Godot 4 Android (renderer Compatibility).

## Como testar
1. Baixe o ZIP do repositorio pelo navegador GitHub.
2. Extraia os arquivos no Android.
3. Abra o editor Godot e importe o arquivo `project.godot`.
4. Execute a cena principal.

## Recursos
- Corrida 3D automatica entre dois carros geometricos.
- Modo Funk Drift com movimento estilizado.
- Botoes para simular curtidas, comentarios e presentes.
- Interface touch e ambiente 3D leve.

## Limites
Nao testado no Redmi Note 10S. Nao ha integracao TikTok, musica, multiplayer ou fisica realista nesta versao. Interacoes sao simuladas offline. Use apenas musica licenciada para lives e integracoes autorizadas.
